# 🧮 Java Console Calculator

## 📌 Overview
This project is a basic **console-based calculator** built using Java.  
It allows users to perform simple arithmetic operations like addition, subtraction, multiplication, and division through terminal input.

---

## 🎯 Objective
The goal of this project is to understand and practice:
- Java syntax
- Methods (functions)
- Loops and conditional statements
- User input using Scanner

---

## 🛠️ Technologies Used
- Java (JDK)
- VS Code / IntelliJ IDEA Community Edition
- Command Prompt / Terminal

---

## ⚙️ Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔁 Perform multiple calculations in a loop
- ❌ Exit option
